# Photography Shoot Plan Skill

一个面向摄影参考收集与现场执行的 Codex Skill。它把参考作品整理成连续编号的拍摄卡片，并按用户选择交付为飞书文档或经过渲染验证的 PDF。

> Skill 名称暂时保留为 `feishu-photography-shoot-plan`，以兼容已有调用；当前能力已经覆盖飞书和 PDF 两种交付方式。

## 能做什么

- 搜集或接收摄影参考，保留原帖链接、创作者和作品标题。
- 检查景别、姿态、机位、光线和拍摄顺序，避免近似图片重复填充。
- 为每张参考图生成三条现场可执行信息：`机位｜`、`光线｜`、`口令｜`。
- 默认将 24 张参考拆成两块连续编号的 3×4 拍摄板，并生成独立来源图库。
- 支持新建方案，也支持对已有飞书文档或 PDF 做定向更新。
- 在交付前验证图片数量、编号连续性、来源顺序、原始比例和文字可读性。

## 交付方式

| 模式 | 适用场景 | 交付与验证 |
| --- | --- | --- |
| 飞书文档 | 需要在线协作、继续编辑或共享画板 | 使用飞书文档与画板；写入后回读节点并重新导出预览 |
| PDF | 需要直接下载、打印或离线查看 | 直接从拍摄计划生成 PDF；逐页重开、提取文本并渲染检查 |

- Skill 不会在用户未选择时擅自默认交付方式。
- 除非用户明确要求，不会同时创建飞书文档和 PDF。

## 使用方式

- 在 Codex 中调用：`$feishu-photography-shoot-plan`
- 新方案示例：

```text
使用 $feishu-photography-shoot-plan，为我的古风夜景人像整理 24 张拍摄参考。
先让我选择飞书文档或 PDF，再生成两块 3×4 拍摄板和来源图库。
```

- 更新方案示例：

```text
使用 $feishu-photography-shoot-plan，更新这个已有 PDF 的第 07–10 张参考图。
保持其他图片、编号、文字和版式不变。
```

## 工作流程

- 确认交付方式、主题、数量、场地、道具、光线方向和安全边界。
- 收集并筛选有明确差异的参考作品，记录来源清单。
- 生成 `shot-plan.json`，为每张图补齐机位、光线和模特口令。
- 运行结构校验器，修复错误并人工检查警告。
- 按飞书或 PDF 的专属布局流程生成成品。
- 对实际交付物做结构和视觉回读，不能只以“写入成功”作为完成标准。

## 核心文件

- `SKILL.md`：入口、任务路由、交付选择和共同质量标准。
- `references/shot-plan-schema.md`：拍摄计划的数据结构。
- `references/whiteboard-layout.md`：飞书画板布局与在线回读规则。
- `references/pdf-layout.md`：PDF 页面设计、生成和逐页验收规则。
- `references/source-gallery.md`：来源图库、链接和图片顺序规范。
- `scripts/validate_plan.py`：在排版前检查 `shot-plan.json`。

## 校验拍摄计划

```bash
python3 scripts/validate_plan.py /path/to/shot-plan.json
```

- 所有错误必须修复后才能进入排版。
- 警告用于提示人工检查，不应通过复制图片或删除必要信息来规避。

## 设计原则

- 成品先于装饰：优先保证构图、光线、表达和现场可执行性。
- 一卡一图：不使用拼图或近似图片凑数。
- 来源可追溯：不编造创作者、作品标题、链接或原始拍摄参数。
- 图片不拉伸：来源图库保留完整单图和原始宽高比。
- 风险落到具体卡片：刀具、移动、泼水或其他风险动作必须写明替代方案或取消条件。
- 交付必须可验证：飞书检查实时画板，PDF 检查最终渲染页面。
